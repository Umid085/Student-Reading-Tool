================================================================================
CORE CONCEPT: THE FORMULA
================================================================================

masterScore = (avgQuizScore × 0.5) + (vocabMastery × 0.3) + (readingSpeed × 0.2)

Range: 0–1 (0–100%)

Recommendation Logic:
  masterScore >= 0.80  → UPGRADE (e.g., A2 → B1)
  masterScore < 0.50   → DOWNGRADE (e.g., B1 → A2)
  0.50 ≤ score < 0.80  → STAY (continue current level)

Hysteresis: Require 2 consecutive quizzes suggesting same direction
            before applying recommendation

Example:
  Student at A2: 81% quiz + 75% vocab + 110 WPM (target 115)
  → masterScore = (0.81 × 0.5) + (0.75 × 0.3) + (0.957 × 0.2)
                = 0.405 + 0.225 + 0.191 = 0.821 (82.1%)
  → >= 0.80? YES → Recommend B1 ✓

================================================================================
KEY DESIGN DECISIONS
================================================================================

✓ Weighted average (50% quiz, 30% vocab, 20% speed)
  → Quiz comprehension most important; vocabulary secondary

✓ Thresholds at 0.80 and 0.50
  → Based on Bloom's taxonomy and educational research

✓ Hysteresis (2+ quizzes required)
  → Prevents single bad/good day from bouncing levels

✓ Max 1-level jump
  → CEFR gaps too large; A1→B1 skips critical A2 grammar

✓ Firebase + localStorage fallback
  → Works offline; syncs across devices

✓ Async Firebase writes
  → Non-blocking; UI never waits for network

✓ No new npm dependencies
  → Uses standard JavaScript + existing APIs

================================================================================
EDGE CASES HANDLED (10 SCENARIOS)
================================================================================

1. First quiz at a level         → No hysteresis yet
2. Manual level selection         → Reset tracking, preserve history
3. Level repeated (10+ quizzes)  → Rolling 5-quiz average, no forced advancement
4. Vocabulary not tracked        → Default vocabMastery = 0.5
5. Network failure               → localStorage fallback, retry on reconnect
6. Missing WPM data              → Assume 0, reduces score but doesn't block
7. Level jump anomaly (A1→C1)    → Flag for admin review
8. Quiz score volatility         → Hysteresis prevents ping-pong
9. Student regresses then improves → Direction consistency check (future)
10. Multiple devices             → Firebase sync, localStorage cache
