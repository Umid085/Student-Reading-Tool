### TIER 3: COMPLEMENTARY TEAM (Quarterly)

**Size:** 2-3 people  
**Time Commitment:** 20-30% (quarterly initiatives)  
**Meeting Cadence:** Monthly strategy, quarterly reviews  
**Decision Authority:** Low-Medium (advisory, insights-driven)

| Role | Focus | Examples |
|------|-------|----------|
| 📈 **Data Scientist** | Learning analytics, churn prediction, personalization | Month 2+ (need user data first) |
| 🔬 **User Researcher** | UX research, usability testing, user interviews | Quarterly feature validation |
| 🚀 **Growth Strategist** | User acquisition, retention optimization, A/B testing | Quarter 2+ (post-launch) |

**When to Invoke:**
```
/agent data-scientist "Analyze student progression curves—is CEFR difficulty effective?"
/agent ux-researcher "Usability test: are students confused by any feature?"
/agent growth-strategist "How do we improve from 1k to 10k students in 6 months?"
```

## 🔄 Collaboration Patterns

### Pattern 1: Typical Feature Development
```
TIER 2 (PM) → Proposes feature
TIER 1 (Core) → Designs & builds
TIER 2 (A11y) → Validates accessibility
TIER 3 (UX Research) → Tests with users
TIER 1 (QA) → Final testing
TIER 4 (DevOps) → Deploys
```

### Pattern 2: Performance Problem
```
TIER 1 (QA) → Identifies slowness
TIER 3 (Data Scientist) → Analyzes root cause
TIER 1 (Backend) → Optimizes
TIER 1 (QA) → Validates improvement
TIER 3 (Growth) → Measures impact
```

### Pattern 3: Strategic Planning
```
TIER 2 (PM) → Sets direction
TIER 1 (EdTech) → Validates learning goals
TIER 3 (Data) → Analyzes current state
TIER 1 + TIER 2 → Prioritizes work
TIER 4 (Optional) → Specialized input
```
