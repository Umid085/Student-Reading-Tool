## 💡 Key Principles

### 1. **Right Person for the Job**
Each tier has specialists focused on their domain. Don't use frontend engineer for strategy; use product manager.

### 2. **Collaboration Over Silos**
Tiers work together. Frontend talks to Tier 2 (accessibility), Tier 1 talks to Tier 3 (data insights).

### 3. **Data-Driven Decisions**
Tier 3 provides data. Tier 2 uses it for prioritization. Tier 1 builds. Tier 4 measures.

### 4. **Scale Intentionally**
Start with Tier 1 (5 people) → Add Tier 2 month 1 → Tier 3 month 2 → Tier 4 as needed.

### 5. **Toolkit Leverage**
135+ agents, 35+ skills available to ALL tiers. Use them liberally.
